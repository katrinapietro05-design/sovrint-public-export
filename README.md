## Public application modules

### Karmic Bills

A functional, mobile-first ledger for unresolved actions, obligations, exchanges, harms, promises, accountability, evidence, repair, lineage, and closure.

Module directory: `apps/karmic-bills/`

Primary integration route: `/karmic-bills`

The package includes a standalone interface, versioned local persistence, audit history, evidence and repair registers, import/export, analytics, printable summaries, a portable schema, and an integration manifest for Sovereign Systems Hub.
